# 开发能力

记录跨设备可复用的开发和验证入口。项目自己的构建、测试和格式规则优先。

## 当前入口

- `rg`：当前设备可调用；优先用于代码和文件搜索。
- `git`：当前设备可调用；按项目规则检查工作区、diff、分支和验收状态。
- `python3`、`node`、`npm`：当前设备可调用；版本和项目包管理器以当前项目配置为准。
- `jq`：当前设备可调用；适合检查 JSON 和机器输出。
- `ffmpeg`：当前设备可调用；涉及音视频时先核实输入格式和项目要求。
- `~/.agents/skills/`：当前用户级 Skill 目录；按任务匹配 Skill，不读取全部内容。

## 使用边界

项目的运行时、包管理、构建、测试和格式规则优先。工具是否安装不等于本次调用一定可用，使用前核实版本、输入输出和作用域。本文件不记录凭证或未经当前环境核实的版本结论。
